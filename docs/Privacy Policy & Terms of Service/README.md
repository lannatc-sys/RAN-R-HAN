# ชุดเอกสารทางกฎหมายและนโยบายความเป็นส่วนตัว (RAN-R-HAN)

โฟลเดอร์นี้จัดเก็บเอกสารสัญญา ข้อกำหนดการใช้งาน และนโยบายความเป็นส่วนตัวสำหรับระบบ RAN-R-HAN

> 🆕 **รอบปรับปรุงที่ 2 (2026-09-10):** อัปเดตเอกสารทุกฉบับให้ครอบคลุม **ระบบ Rider Dispatch** ตาม [`../03-rider-system-architecture.md`](../03-rider-system-architecture.md) — เพิ่มขอบเขตไรเดอร์ในฐานะเจ้าของข้อมูล, แก้ข้อความ Live Tracking ที่เคยขัดกับระบบจริง, ปรับถ้อยคำ Safe Drop/Cancellation, เพิ่มรายการตรวจสอบทางกฎหมายใหม่ 7 ข้อใน Checklist (1.6–1.12) ยังต้อง**สร้าง Rider Agreement เป็นเอกสารแยกต่างหาก ซึ่งยังไม่มีอยู่ในโฟลเดอร์นี้** ก่อนเปิดรับสมัครไรเดอร์จริง — **`.docx` ฉบับรวมยังไม่ถูก regenerate ตามรอบนี้ ต้องสร้างใหม่ก่อนส่งทนาย**
